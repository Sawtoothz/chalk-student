## Highlight colours in annotated.pdf

| Colour | Meaning |
| --- | --- |
| green | definition or assumption |
| yellow | key idea or result |
| red box | equation you will derive and implement |
| orange | where it fails |
| blue | link to your robots or another lesson |
| gray note icon | section-level reading verdict |

## Suggested order (about 9 hours)

1. `map.md`, then read the chapter with `annotated.pdf` open (3.6 h must-read, 40 min skim).
2. `lecture.md` L1–L4, session Fig 2.3a–b (1 h).
3. `lecture.md` L5–L11, session Fig 2.3c–e (1 h).
4. T1 and T2 on paper (1 h).
5. T3 with `translate.md` beside you; `just test thrun-pr 4` until green (2 h).
6. T4 (30 min).
7. T5 on a free evening: it is the one that transfers to a robot on a real field.

## How this package was checked

- `scripts/check_package.py`: structure, 135 highlights placed, reference solution passes all 27 oracle tests,
  shipped stubs fail them, T4 broken file fails its grader, session executes. Verdict: ship.
- A separate reviewer agent compared every cited equation and page against the book (report in `REVIEW.md`).
- Every number in the lecture comes from `figures/numbers.json`; every T5 reference number from running the
  reference solution on the shipped data (`exercises/solutions/T5_numbers.json`).
- Session readouts are identical in `session.py` and `interactive.html` at the default settings (`REVIEW.md`).
