## Highlight colours in annotated.pdf

| Colour | Meaning |
| --- | --- |
| green | definition or assumption |
| yellow | key idea or result |
| red box | equation you will derive and implement |
| orange | where it fails |
| blue | link to your robots or another lesson |
| gray note icon | section-level reading verdict |

## Suggested order (about 10 hours, plus T5)

1. `map.md`, then read the chapter with `annotated.pdf` open (about 3.5 h with the skim sections).
2. `lecture.md` L1–L5, then `session.py` Fig 2.4a–b (1 h).
3. T1 and T2 on paper (1 h). T2.2 is the bisector algebra where Table 5.1 loses the sign of v̂.
4. T3 with `translate.md` beside you; `pytest exercises/tests/test_T3.py` until green (about 4 h, map.md's estimate).
5. `lecture.md` L6–L9, session Fig 2.4c–d, T4 (45 min).
6. T5 when you next have a free evening: it is the one that transfers to the tracked robot.

## How this package was checked

- `scripts/check_package.py`: structure, figures, 117 highlights placed, the reference solution passes all 50
  oracle tests, the shipped stubs fail them, the T4 broken file fails its grader, the session executes.
- `figures/card_checks.py`: every card code block runs, the C++ compiles and agrees with the Python, every robust
  card function agrees with `T3_solution.py` on random inputs, and 19 of 19 quoted numbers are found.
- `figures/check_interactive.py`: 21 slider scenarios, every readout identical in `session.py` and `interactive.html`.
- `teach-reviewer` compared every table, equation and cited page against the book (`REVIEW.md`).
- All reference numbers were produced by running the reference solution or `make_figures.py` in this repo.
