## Highlight colours in annotated.pdf

| Colour | Meaning |
| --- | --- |
| green | definition or assumption |
| yellow | key idea or result |
| red box | equation you will derive and implement |
| orange | where it fails |
| blue | link to your robots or another lesson |
| gray note icon | section-level reading verdict |

## Suggested order (about 8 hours)

1. `map.md`, then read the chapter with `annotated.pdf` open (3.5 h).
2. `lecture.md` L1–L3, then `session.py` Fig 2.2a–b (1 h).
3. T1 and T2 on paper (1 h).
4. T3 with `translate.md` beside you; `pytest exercises/tests/test_T3.py` until green (2 h).
5. `lecture.md` L4–L6, session Fig 2.2c–d, T4 (45 min).
6. T5 when you next have a free evening; it is the one that transfers to the real robot.

## How this package was checked

- `scripts/check_package.py`: structure, figures, highlight placement, reference solution passes all 33
  oracle tests, shipped stubs fail them, T4 broken file fails its grader, session executes.
- A separate reviewer agent compared every cited equation and page against the book (report in
  `REVIEW.md`).
- All T5 reference numbers were produced by running the reference solution on the shipped data.
